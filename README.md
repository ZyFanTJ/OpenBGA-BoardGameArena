# Moon Table

可扩展的多人在线桌游平台。已接入 **CABO · 2019 英文第二版** 、**魔毯商人 · Marrakech** 和 **七大奇迹 · 2020 第二版（含领袖与舰队）**，各游戏支持 2–4 / 3–7 人、房间码邀请、准备开局、即时聊天、私密看牌、跨轮计分和刷新重连。

## 本地运行

Docker 一键运行：`docker compose up -d --build --wait`，打开 <http://127.0.0.1:3100/>。镜像导出、仓库上传和域名 HTTPS 配置见 [Docker 部署](docs/deployment.md)。

需要 Node.js 22 或更新版本。没有第三方运行依赖，无需安装依赖或构建。

```sh
npm start
```

打开 http://127.0.0.1:3000 。首次访问直接显示完整游戏大厅；点击「开个房间」，选择桌游类型（CABO / 魔毯商人 / 七大奇迹）、填写昵称和房间名称即可创建，也可直接使用房间码加入。已有对局的身份刷新后会回到原房间。

第二位玩家使用另一个浏览器/独立无痕窗口访问相同地址，输入房间码加入。也可以在本机分别使用 `127.0.0.1:3000` 与 `localhost:3000` 获得两个独立 Cookie 身份。

单人练习：创建房间 → 点击空座位的「添加 AI」（CABO/魔毯商人最多 3 位，七大奇迹最多 6 位）→「我准备好了」→「开始游戏」。AI 自动看起始牌、抽换牌、使用能力和呼叫 CABO；每轮结算后由房主点击「下一轮」。等待阶段房主可移除 AI，再邀请真人加入。七大奇迹至少需要 3 人，可添加 2–6 位 AI；其 AI 自动选面、选牌和处理特殊能力。无需 API Key 或外部模型服务。

```sh
npm test
npm run dev
```

`dev` 在服务端文件变化时重启进程；页面代码变化后手动刷新。房间状态写入 `.data/platform.json`，重启后保留。浏览器保留会话 Cookie 时可回到原座位。

首页素材使用无损 WebP 和独立封面裁片，桌游界面进入牌桌后按需加载；公共静态文件支持压缩和缓存校验。详见 [性能优化与验证](docs/performance.md)。

默认只监听本机。局域网多人测试可以在 PowerShell 中使用：

```powershell
$env:HOST = '0.0.0.0'
npm start
```

其他设备访问主机局域网 IP 的 3000 端口；系统防火墙须允许对应访问。`PORT` 可修改端口，`DATA_FILE` 可指定数据文件；HTTPS 反向代理部署时设 `SECURE_COOKIES=1`。

## 目录边界

```text
apps/
  server/              HTTP、静态资源、Cookie、SSE 传输
  web/                 大厅、房间和聊天界面
    games/             游戏专属牌桌渲染器
packages/
  platform/            房间、会话、存储、通用游戏接口
  games/
    registry.js        服务端游戏注册表
    cabo/              CABO 纯规则状态机、视图、计分
    marrakech/         魔毯商人规则、棋盘几何、AI
    seven-wonders/     七大奇迹卡牌、同时选牌、贸易、计分与 AI
tests/                 规则、信息隔离、平台扩展和 HTTP 集成测试
docs/
  architecture.md      模块边界、扩展策略与演进取舍
  adding-a-game.md     新游戏接入步骤
  cabo-rules.md        规则来源与线上边界处理
  protocol.md          API 与并发约定
```

代码采用原生 JavaScript ES Modules，接口另有 TypeScript 声明用于描述边界。该声明不是已启用的静态类型检查。规则函数与网络、文件、DOM 完全分离；随机数由平台注入，生产使用 Node crypto，测试使用固定种子。

## 已完成

- 游戏大厅：原创桌面与月夜素材、游戏封面、分类搜索、公开房间与 AI 练习。
- 玩家论坛：导航进入「玩家论坛」，发布功能建议、桌游心愿与闲聊，支持回复、支持、分类搜索和结束讨论；联系方式选填。无需注册即可浏览，填写昵称即可参与，话题链接可直接分享。论坛、好友、战绩和商城使用统一的头部与导航排版，切换和加载时保持对齐。
- 好友与账号：申请、在线状态、房间邀请、游客绑定账号、跨设备登录与个人档案。
- 真实战绩：三个桌游自动归档，胜负 / 桌游 / AI 筛选、最终排名、计分明细与对局奖励。
- 外观商城：星辉兑换、装备预览、角色头像、名片背景和称号；余额、库存与装备在服务端保存。原创场景与角色图集，桌面 / 手机自适应，见 [功能与美术说明](docs/hub.md)。
- Docker：构建时运行全套测试、非 root 容器、持久化数据卷、健康检查与一键启动；提供离线镜像包、仓库上传脚本与 HTTPS 部署配置，见 [部署文档](docs/deployment.md)。

- 私人房间：创建、加入、准备、房主开局、空房删除、中途退出与 AI 接管、房主转移、全员投票解散。
- 本地 AI：房主添加/移除、自动准备与回合、有限信息记忆、服务重启后自动继续；基础练习策略，见 [AI 玩家](docs/bots.md)。
- CABO：起始看两张、牌库/弃牌堆抽牌、单张/多张交换、换牌失败惩罚、PEEK/SPY/SWAP、CABO 最后回合、牌库耗尽、Kamikaze、100 分回退、整场胜负、下一轮与再开一局；可选专家模式。
- 魔毯商人：2–4 人、转向与专用骰、边缘折返、同色连通区域收费、铺毯覆盖、破产淘汰、终局计分；基础 AI、独立 SVG 棋盘、移动/铺毯动画和手机玩法手卡，见 [规则说明](docs/marrakech-rules.md)。
- 七大奇迹：3–7 人、七座日夜奇迹、三时代同时选牌、资源贸易、连锁、特殊能力、军事与科技/行会计分；AI 陪练与刷新恢复，见 [规则说明](docs/seven-wonders-rules.md)。77 种原创卡牌插画、七座奇迹与独立资源图标，手牌与操作集中展示，城市和规则按需展开。见 [美术素材与维护](assets/seven-wonders/README.md)。
- 服务端权威状态与玩家专属投影；客户端拿不到完整牌库或其他人的暗牌。
- 连贯出牌动画：发牌、抽换牌、弃牌、能力、补罚牌和结算翻面；真人与 AI 同步播放，尊重减少动态效果设置，见 [动作设计](docs/cabo-motion.md)。
- SSE 实时更新及自动重连、动作版本校验、有限聊天历史、基本频率与请求大小限制。
- 单进程事务式 JSON 存档；失败动作不会污染内存状态。
- 自动化规则/HTTP 集成测试，以及第二种同时行动游戏的接口兼容测试。

## 当前边界

存储适配器是单进程整文件事务，一个数据卷仅供一个实例使用；没有分布式锁、观战或匹配系统。账号支持跨设备恢复，游客清除 Cookie 前需先绑定；当前没有邮箱找回密码。仅断线时保留座位，不自动托管或踢人；主动退出会由 AI 接管。全员解散投票不会把断线当作同意。过期会话在新建会话时清理，战绩与历史房间尚未做容量归档。商城采用对局星辉，不涉及真实货币支付。

平台接口不限定轮流行动，但当前传输和同步面向离散行动桌游；高频实时物理游戏需要不同的同步模型。状态版本不匹配会拒绝行动，应先实现迁移，不自动解释旧存档。

扩展之前先阅读 [架构设计](docs/architecture.md) 和 [新游戏接入](docs/adding-a-game.md)。规则与线上处理细节见 [CABO 规则说明](docs/cabo-rules.md)。

七大奇迹现支持第二版领袖、专家领袖、舰队单独或同时开启。创建房间时选择，房主也可在准备区修改；修改后真人需要重新准备。具体规则、来源和验证见 [扩展规则](docs/seven-wonders-expansions.md)。七大奇迹存档 v1 会自动迁移为 v2，旧对局继续按基础版进行。

管理员后台提供用户、星辉、系统配置和审计管理；首位管理员绑定和权限说明见 [管理中心](docs/administration.md)。
