# 德州扑克素材

发布文件位于 `apps/web/assets/texas-holdem/`。本次为 Moon Table 原创绘制 SVG，未复制第三方牌面、标识或界面截图，不需要外链字体和图片。

| 文件 | 用途 |
| --- | --- |
| cover.svg | 768 × 512 大厅封面，绿绒桌、A/K、筹码与庄家钮 |
| card-back.svg | 80 × 112 月纹牌背，共享公开牌背 |
| chips.svg | 104 × 80 双色筹码堆，底池和下注标记 |

52 张牌面由 `games/texas-holdem/art.js` 以可访问 HTML 绘制，四种花色同时使用不同符号与颜色；点数作为真实文本保留。桌布、桌沿和高亮由独立 CSS 绘制，支持高像素密度和减少动画设置。所有资源随仓库本地提供。

设计研究及参考来源见 `docs/texas-holdem-ui.md`。素材仅体现桌内游戏筹码，不关联星辉或账户资产。
