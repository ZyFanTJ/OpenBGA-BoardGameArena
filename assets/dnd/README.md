# 雾灯纪行美术素材

使用内置 **image_gen** 制作的原创像素风奇幻 RPG 美术。三套剧本的全部 23 个场景均有独立背景。场景不烘焙人物；角色、NPC、敌人与交互物品分别合成，按当前玩家视图显示。

共 **78 个 WebP 文件，3,893,676 字节（约 3.9 MB）**。按页面使用情况加载，不会一次下载整套素材。实际数量、尺寸、逐文件字节数及 SHA-256 以 [manifest.json](manifest.json) 为准。

- 网页素材：`apps/web/assets/dnd/`。
- 原始选定图集：[source-atlases](source-atlases/)，六张 PNG。生成时的原文件同时保留在本机 Codex generated_images 目录。
- 最终生成提示词：[prompts.json](prompts.json)。使用内置工具，没有调用项目的 DM 测试密钥或后备图片 CLI。
- 重新导出：在仓库根目录使用带 Pillow 的 Python 运行 `scripts/prepare-dnd-art.py`。脚本只拆分已生成像素、保留透明度、加入透明留白、生成头像裁切并编码 WebP，不发起模型请求。图集中的人物不是精确网格，脚本按独立透明对象提取，避免切断武器、披风与脚部。

## 画面与交互

使用深青阴影、黄铜与烛光、清晰的像素簇和不同场景的材质。黑苹果有蓝玻璃温室、紫绿衣帽间与金色宴会；摩根堡有冷河、破石与地下营地；雾灯有寒雾和暖灯。全身立绘是可合成的 2D 人物资源，不是可自由行走的 3D 模型。NPC 的轻微呼吸效果使用 CSS，遵循减少动态效果偏好。

`apps/web/games/dnd/art.js` 管理已知素材 URL、场景演员与物品映射；`art.css` 管理手机 / 宽屏构图、人物位置与透明立绘。未知素材仍走既有图标和矢量场景回退。场景、人物名、HP、选中敌人和可行动状态来自服务端玩家视图，图像不判定规则。

演员通过当前公开实体筛选，战斗时场景 NPC 让位于敌人目标。物品图标用于真实对象、药水数量与已获得的线索；不替代原有名称、资源数量或判定说明。重复的矿工 / 儿童形象是同类人物共用美术，不表示原作角色被合并成同一个人。
