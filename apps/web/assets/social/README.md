# 结算分享卡片

`moon-card-v1.webp` 是无文字插画底图，使用内置 imagegen 生成，随后转换为 WebP；未使用 CLI 或外部 API。字号、昵称、胜负、分数、名次和底部域名由 `apps/web/result-card.js` 在浏览器动态绘制。该素材仅用于结算分享，不参与游戏状态或规则。

## 生成提示词

原型方向：成熟桌游俱乐部名片，深青底 #0b3038、玉色 #88b9a6、暖象牙色 #eee8d2、香槟金 #d4bb7e。横向 1.6:1，平面正视，细腻纸纹、克制的金箔雕刻线条、充足留白。右侧月相与轨道、几何织毯和桌游氛围插画；左侧 Moon Table 品牌、魔毯商人标题、月见头像与 51 分优胜信息，底部紧凑两人排位带。避免仪表盘、霓虹、夸张奖杯和长段说明。

底图编辑提示词：保留原型的深青纸纹、右侧香槟金雕刻月相、轨道、城市剪影、织毯与灯笼。删去所有文字、数字、头像圆框、徽章、横线和标识，将移除区域自然填充为深青纸纹。左侧 55% 保持安静留白，底部 24% 渐变为近乎均匀的深青色供动态排位覆盖。减弱具体摩洛哥地标，改为抽象城市。无任何文字、数字、水印、透视或外部投影。

## 维护

保持底图无文字，新增游戏不需要生成新的文字图片。多人排位采用两列或三列，并动态增加画布高度；长昵称自适应缩小，排位带按实际空间省略，完整名字保留在可访问描述里。图片加载成功后才可下载，图文共同导出为 PNG。
