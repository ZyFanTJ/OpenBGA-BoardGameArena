## 头像框与称号

头像框在原有虹光、鎏金、月蚀基础上增加樱庭、机甲、赤羽、深空、森灵五种主题。每款包含独立 SVG 装饰、内外轨道与分层动效，皇冠、羽翼、花枝、晶体及机械护角不会遮盖头像中心。

称号增加月相预言家、不灭之羽、深海回响、零号玩家、花间一梦、命运掷骰人、虚空行者、一剑霜寒、摸鱼茶话家、追光旅人。各自使用独立徽章与主题动画，包括月星明灭、展翼、潮线、信号跳变、花瓣转动、浮空骰子、星轨、剑光、茶汽与彗星漂移。

矢量图案在 `apps/web/hub/cosmetic-art.js`，通过 `cosmetics.js` 统一供商城、个人资料、好友和牌桌使用。称号主题由白名单中的公开 ID 解析，不新增私密资料或持久化字段。购买与装备继续使用现有事务和 revision 检查。

装饰不响应鼠标事件，动画以 transform / opacity 为主，支持 `prefers-reduced-motion: reduce`。原有称号保留原来的等级徽章。商城标明各类风格和动态藏品。
