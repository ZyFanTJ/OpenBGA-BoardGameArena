# 德州扑克界面与交互

## 参考与取舍

2026-10-24 参考 [PokerStars 下注滑杆说明](https://www.pokerstars.com/help/articles/bet-slider-options/) 中滑杆、精确金额和快捷下注的组合，以及其[牌桌外观设置](https://www.pokerstars.com/help/articles/table-appearance-feature/)和[德州流程说明](https://www.pokerstars.com/poker/games/texas-holdem/)。采用常见的椭圆桌、中央公共牌和底池、环绕玩家座位、底部本人手牌和行动区；不复制第三方界面或商业素材。

沿用 Moon Table 的深青绿与浅金配色、头像、称号、回合高亮、房间菜单、聊天、解散投票和终局操作。牌面使用四种花色符号和颜色，数字作为文本提供清晰的读屏标签。原创封面、月纹牌背与筹码源文件见 `assets/texas-holdem/README.md`。

## 行动与反馈

- 座位同时显示剩余筹码、当前街投入、最后行动、庄家/盲注和当前行动者；淘汰与弃牌有独立文字状态，不能仅凭颜色判断。
- 公共牌区保留五个位置；未发牌为空槽，隐藏底牌始终为牌背。新公共牌轻量淡入，遵循系统减少动画偏好。
- 固定顺序呈现弃牌、过牌/跟注、下注/加注。合法性由服务端 `legal` 投影决定；机器人与限时动作也使用投影。
- 提供最小、半底池、底池、全押预设，以及滑杆与精确数字输入。面对下注时，底池预设采用跟注后的底池计算加注幅度。
- “加注到”表示本街累计投入；确认区同时显示此次扣除与余下筹码。无成本过牌时误点弃牌需再次确认。按钮待响应期间禁用；房间 revision 校验拒绝旧动作。
- 规则与记录采用原生对话框，可用 Tab 导航、Escape 关闭，更新时尽量保留输入、焦点和面板滚动位置。
- 每手结算展示主池/边池分配、退回、各人牌型、净变化与余额；仅对本人高亮最终最佳五张。最终比赛接入分享战绩、返回房间和再来一局。

## 响应式与加载

德州界面、样式与观战模块独立按需加载。手机保留八个座位、可读底牌与公共牌，将昵称和下注控制收紧；纵向滚动可查看完整牌局及结算。窄屏不横向截断核心操作。所有素材本地加载，不依赖第三方 CDN。
