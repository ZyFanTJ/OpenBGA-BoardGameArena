# 七大奇迹 HUD 与信息层级

视觉采用深色指挥台、象牙白文字、黄铜重点色、直角边框和独立类别色。插画保留氛围，数字、状态、资源与操作影响拥有更高识别优先级。

- 顶部显示时代、回合进度、传牌方向与全桌确认状态。游戏进行时收起平台主导航，房间码、聊天和房间菜单保留。
- 桌面中央为自己的城市，左右为真实邻国。邻国显示公开军力比较与可购买产能，其他玩家只在确认栏占据紧凑位置。
- 城市固定显示七种产能，包括零值；任选产能另行成组，不把任选一份误算成多份。钱币、军力、三类科技和七色建筑数量集中呈现。点击分类数量即可按颜色查询已建建筑。
- 卡面以明显的类别色、大字名称和效果数值为重点，费用固定在底部。实际付款额、连锁免费、奇迹能力免费和不可建造分别表示。细则与连锁前后继按需展开。
- 行动弹层显示自身收支、永久产能、军力或科技计分的前后变化，资源来源分为自有、左邻和右邻。建造奇迹使用牌背表示所选牌被作为建材；卖牌只显示对应钱币变化。
- 商业、行会显示统计范围与条件。计分、军力与计数收入依据当前公开城市预览；本轮尚未揭晓的对手选择不会进入预览。邻国计数收入使用估算符号，自身收支不包含未来邻国付款。
- 手机优先显示自己的城市与可横滑的手牌，邻国位于手牌之后；提供左右浏览按钮。相同回合的服务端推送保留手牌滚动位置，查看城市后保留选牌、用途及付款选择。

规则模块仅在玩家视图中增加预览、资源分配说明与连锁目录。规则判定仍使用原有付款结构；存储状态与版本保持不变，不把这些显示字段写入 pending 或 lastActions。

验收覆盖 77 种卡牌、320–1536 px 九种屏宽、完整三个时代、七人桌、键盘、科技套组、任选资源、连锁、奇迹牌背、卖牌、付款来源与滚动保留。临时脚本、截图和游戏数据位于被忽略的 work/ 中。
