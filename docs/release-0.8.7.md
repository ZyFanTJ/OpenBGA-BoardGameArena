# 0.8.7 更新内容

2026-10-24。相对云端 0.8.6 维护版整理。

- **德州扑克**：新增 2–8 人无上限桌内筹码赛、AI、边池与全押处理、下注预览、结算和战绩。筹码仅用于本场，不从账户星辉扣款。
- **观战与规则**：各游戏增加独立的公开观战投影，房主可控制观战；准备区和游戏中提供图解玩法手卡。观众无法操作牌局或查看隐藏手牌。
- **大厅与房间**：调整首页布局，展示可加入牌桌、最近游玩、AI 陪练及更新日志；优化建房设置、邀请面板与手机游戏界面。
- **加载与查询**：商城、历史、论坛、管理中心和游戏资源按需加载；展示图片压缩；相同在途查询合并；增加派生查询索引和论坛逐话题持久化，减少无关数据读取和重写。
- **账号与管理**：优化游客绑定账号的会话核验，管理员可重置注册账号密码、控制单款游戏开放，并维护页脚信息。上线不会主动重置任何账号密码。
- **历史与资产**：保留个人历史副本的隔离，避免其他玩家战绩重复计算；历史对局按实际真人参与人数修正练习／真人分类，不重新发放或扣回既有奖励。

平台逻辑数据版本仍为 v9，既有游戏存档结构和版本不变。论坛 SQLite 物理记录调整会在事务内完成；回退旧程序需要恢复升级前整卷备份。发布不复制本地开发数据到云端。

已发布到云端，健康接口返回 0.8.7。本地与云端构建均通过 427 项测试；发布前校验全部 352 个公开资源，发布后公网核验 118 个重点资源。现有账号、资产、战绩、会话、论坛和 AI 配置保留，完整备份已保存，存储迁移与恢复已演练。详细发布及回退记录见 [remote-deployment.md](remote-deployment.md)。
