# CABO 牌桌界面

本版使用用户提供的 `assets/cabo/reference-style/cabo-atlas-v1.png`。通过 4×4 CSS sprite 显示 0–13 及统一牌背，叠加清晰数字和 PEEK/SPY/SWAP 标识；素材原文件和 manifest 保留，未混入旧探索图或 Kenney 卡面。静态服务器只为该 PNG 提供明确的公开路径。

## 视角与操作

- 当前玩家固定在下方。四人时，顺时针后续座位依次在左、上、右；两人时对手在上方，三人时对手在左右。
- 卡片仍按引擎给出的牌位顺序显示，不按数字排序。窄屏的侧面牌列会折行，牌位编号保持不变；本人长牌列支持横向滚动。
- 中央牌库和弃牌可以直接点击。新抽到的牌紧邻牌堆展示，不覆盖可选手牌。
- 底部只显示当前操作提示和可用动作。房间聊天与规则默认收起。
- 暗牌始终使用统一牌背。`cardArt` 只消费服务器玩家投影中的数值；查看能力只绘制收到的该次 reveal，不推断其他牌。

## 模块

- `cabo.js`：本地选牌状态与命令生成。
- `cabo-table.js`：围桌布局、牌堆、玩家信息、当前操作。
- `cabo-cards.js`：图集映射和相对座位映射。
- `cabo.css`：CABO 专属牌桌样式。
- 平台壳仅负责房间顶栏、聊天及游戏渲染器分发。

没有修改规则状态结构或存档版本。测试覆盖 2/3/4 人每个观察者的座位映射、统一暗牌渲染、静态素材路由和真实引擎的界面动作链路。
