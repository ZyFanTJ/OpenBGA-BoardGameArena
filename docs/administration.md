# 管理中心

入口为 `/#admin`。已授权账号登录后，顶部“管理”和手机端“更多 → 管理中心”可直接进入。普通用户、游客和未登录访问者均无法读取管理数据或提交管理命令。

## 首位管理员

先在正常登录页面注册或绑定一个账号，再通过服务端启动配置指定它的登录名：

```env
ADMIN_BOOTSTRAP_HANDLE=your_registered_handle
```

Docker Compose 从项目 `.env` 读取该值并传入应用；原生启动读取同名环境变量。配置的必须是已存在的注册账号，不使用默认管理员密码，不把任意游客或第一个注册者自动升级。首位管理员绑定完成后可清空该配置。已有可用管理员时，此配置不会再次提权其他账号；后续授权和撤销由后台完成。

配置应用重启前需要保留原持久数据卷。账号登录名不等于 SSH 用户名，绑定只影响指定账号的管理权限，不改变星辉、藏品、房间和游戏进度。

## 页面与权限

- 运行总览显示真实用户数、注册与在线人数、当前房间及对局数、余额总量、最近用户和管理操作。
- 用户管理支持昵称、账号、好友码、用户 ID 搜索，注册/游客/管理员/在线/停用筛选，加入时间、访问时间或星辉排序，每页 20 人。档案显示账号和个人资料、好友/藏品数、所在房间、有效会话数、最近收支与战绩；不会返回密码摘要、盐、Cookie、会话令牌或秘密游戏状态。
- 资料修正可修改昵称和简介；保留登录账号、用户 ID、隐私范围、藏品和房间归属。修改昵称后房间和好友使用最新资料，历史聊天和比赛记录保留原有记录。
- 星辉支持设置为目标余额，或用正负数增加/扣减。预览修改后余额；备注必填，余额不得为负。调整同时写入资产流水和管理审计，用户自己的账簿显示“管理员调整”。
- 账号支持停用/恢复、撤销所有设备会话、为注册用户授予或撤销管理员角色。停用立即撤销会话并阻止登录，房间座位保留。不能停用自己或撤销自己的管理权限；至少保留一位可用管理员。恢复后需重新登录，原 Cookie 不恢复。
- 操作记录按时间分页，可搜索操作人、目标、备注，展开查看修改前后的真实值。应用接口不提供删除审计的操作。

## 系统设置

站点名称与公告面向所有玩家，公告留空时隐藏。当前浏览器保存后立即更新，其他已打开页面在约 30 秒内刷新公共设置。

注册、游客入座、创建房间、商城兑换、论坛发帖与回复均有独立开关，由对应领域服务在提交事务内执行。关闭新用户或创建房间不影响现有身份、登录与已有对局；关闭商城兑换仍可装备已有藏品，关闭论坛发帖仍可阅读已有话题。

首次入座赠礼、AI 练习胜利/完成、真人对局胜利/完成的星辉发放可分别设置为 0–100000 的整数。注册绑定不会再次发赠礼；设置只影响今后的新赠礼和对局结算，不重算旧记录或改动已有余额。终局奖励仍按 matchId 和用户去重，中途离席不领奖。

保存设置需要当前设置 revision 和备注；有更新冲突时保持输入并提示重新载入，不覆盖别人的修改。

## 数据和接口

平台存储 v5 → v6 新增 `system` 与 `administration`，默认配置维持原功能和星辉发放。v4 存档先经过论坛 v5 迁移。原文件以其原版本备份，例如 `.v4.bak` 或 `.v5.bak`。游戏内部状态与各游戏状态版本不变；旧镜像不能直接读取 v6，回滚需停止服务并恢复升级前备份。

管理接口使用正常登录会话，并在服务端每次检查注册身份、管理员角色和停用状态；写入事务内再次校验权限。资产/资料修改校验 profile revision，权限修改校验 accessRevision，系统设置校验独立 revision。所有管理写入包含备注和 requestId，同一操作重放不会重复入账或生成重复审计；不同内容不能复用请求标识。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/system` | 公开名称、公告和功能开放状态，不含管理信息 |
| GET | `/api/admin/overview` | 运行总览 |
| GET | `/api/admin/users?q=&filter=&sort=&page=` | 用户分页 |
| GET | `/api/admin/users/:id` | 用户档案 |
| POST | `/api/admin/users/:id/profile` | 修正昵称与简介 |
| POST | `/api/admin/users/:id/credits` | 设置或增减星辉 |
| POST | `/api/admin/users/:id/access` | 权限、停用和会话管理 |
| GET / POST | `/api/admin/settings` | 查看与保存系统设置 |
| GET | `/api/admin/audit?q=&page=` | 操作记录 |

后台沿用应用的同源检查、JSON 内容类型校验、请求大小上限、限速和防止内联脚本执行的 CSP。测试数据与截图仅保存于忽略的 `work/admin-system/`。

## 本次验证

0.5.0 本地镜像构建通过 174 项测试。管理专项覆盖权限绕过、敏感字段投影、分页筛选、星辉与购买的版本冲突、重复请求、权限授权、停用与撤销会话、系统开关及奖励规则、审计、v5 原始备份与纯迁移。实际浏览器经过登录、查看和修正资料、调整星辉、并发修改冲突、授权、停用恢复、保存设置与公告，以及 320/390/768/1280/1440/1920px 布局。最终 Docker 提供的后台资源与源码校验一致，未登录管理接口为 401。
