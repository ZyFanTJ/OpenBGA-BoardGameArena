# 0.8.9 更新内容

2026-10-28。相对云端 0.8.8 整理。

- **潮汐守望 · 群岛防线**：新增 1–4 人合作塔防、AI 队友、起手派系、抽卡合成、建筑部署与进化、互送建筑、悬赏和遗物。战场包含实时敌人、独立防区、地图缩放及玩法手卡。
- **好友私聊与约局**：好友页增加独立私聊和预约游戏，支持发送消息、未读提示、预约确认与取消、临近开局邀请；聊天与预约分别持久化。
- **实时通信**：增加带会话和房间权限验证的 WebSocket 推送、心跳及重连，配合实时游戏调度；每条游戏推送仍使用玩家或观众专属视图，操作指令沿用服务器事务校验。
- **外观与界面**：扩充头像及外观素材、优化商城和好友页、玩家身份展示，以及 CABO 动画与交互反馈。
- **构建与资源**：新增潮汐守望前端与手卡打包、类型检查，运行镜像增加服务器 WebSocket 依赖。

平台数据从 v9 迁移到 **v10**，只增加 `friendConversations` 和 `gameAppointments` 两个独立集合。新游戏使用自身 stateVersion 4，并提供旧版潮汐守望存档迁移；本次上线不改变既有八款游戏的存档版本。回退必须先停服务并恢复升级前完整数据备份。

本地固定快照与服务器构建均通过 **530/530** 项测试，潮汐守望类型检查通过；隔离镜像核验 **393** 个公开资源及 **504** 个运行文件。隔离浏览器验证新游戏建房、AI 入座、起手选择、建筑部署、实时战斗及刷新恢复，好友私聊发送、预约创建及刷新后显示。真实线上数据只读副本通过 v9 → v10 完整迁移、关闭重开与备份恢复检查。

已发布至云端，健康接口返回 0.8.9，公网核验 138 个重点资源通过。现有账号、会话、资产、战绩、好友、论坛和 AI 配置保留。完整备份和旧镜像已保留，详细部署及回退记录见 [remote-deployment.md](remote-deployment.md)。
