## 日常维护

登录服务器后：

```sh
cd /opt/moon-table/current
docker compose -p moon-table ps
docker compose -p moon-table logs --tail 100 app
curl --fail http://127.0.0.1:3100/api/health
docker compose -p moon-table restart app
```

容器配置自动重启、健康检查、只读运行文件系统和独立持久数据卷。普通重启、重新创建容器均保留数据。不要使用 `docker compose down -v` 删除数据卷。

## 数据备份

停止应用后备份同一数据卷，备份文件仅保存在服务器的私有目录，不提交到仓库：

```sh
cd /opt/moon-table/current
umask 077
mkdir -p /opt/moon-table/backups
docker compose -p moon-table stop app
docker run --rm --user 0 --entrypoint tar \
  -v moon-table_moon-data:/data:ro happy-online:0.5.1 \
  -czf - -C /data . > /opt/moon-table/backups/platform-backup.tgz
docker compose -p moon-table up -d --no-build --wait
```

后续更新时保留相同 Compose 项目名和数据卷；在新版本目录完成校验、导入镜像和健康检查后，再更新 `current` 链接。涉及存档版本升级时，遵循 `docs/deployment.md` 中的迁移和回滚约束。
