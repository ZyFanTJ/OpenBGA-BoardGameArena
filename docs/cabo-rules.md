# CABO 规则实现说明

目标版本是 **2019 英文第二版**，不是初版、其他网站的家规或 Deluxe 的修改版。

依据为 [2019 英文规则 PDF](https://cdn.1j1ju.com/medias/81/a9/63-cabo-rulebook.pdf)，对照 [官方规则文件条目](https://boardgamegeek.com/filepage/183443/cabo-second-edition-official-rules) 与 [第二版信息](https://boardgamegeek.com/boardgame/271321/cabo-second-edition)。[规则文本索引](https://www.rulespal.com/cabo/rulebook) 便于逐项查阅。最后核对日期：2026-10-04。

实现覆盖牌库组成、起始查看、三类回合选择、多牌交换及惩罚、三种特殊能力、呼叫后的最后回合、牌库耗尽、逐轮/整场计分、Kamikaze、单次分数回退，以及规则书的 Expert Variant。具体行为以引擎测试为可执行说明。

## 线上实现约定

以下针对纸面规则在 UI 和边界上的落地，不声称规则书逐项规定了线上行为：

- 查看使用“选择—显示—确认盖回”的显式流程，不自动倒计时。后续快照不保留已确认的私密查看结果；玩家自己记忆。
- 抽走最后一张牌后，先完成此次换牌/能力和可能的查看确认，再结算，避免留下尚未处理的抽牌。
- 至少三张的失败换牌需要罚抽，但牌库已空时无法补牌，直接保留已有结果并结算；不回收弃牌重洗来延长本轮。
- 成功多牌交换由玩家选择新牌放在哪个被换出的牌位；当前 UI 采用“第一个被选中的牌位”。其余牌的相对顺序保持，移除空位。
- 失败换牌提供左端/右端选择；若同时加入抽到的牌和罚牌，两张都加入所选一端，罚牌紧随新牌。
- 下轮先手并列时，按上一轮先手起、顺时针选择首个符合者（包含上一轮先手）。
- 终局累计分、最后一轮得分都相同的玩家共同获胜；规则书没有再细化第三层决胜。
- 未加入抢拍/抢弃牌、任意两人交换、13 点特殊能力等家规。

专家模式让玩家面前的牌保持盖住，包括弃牌堆换入及失败交换后留下的牌；它不改变牌堆和计分逻辑。

没有拷贝商业版卡面、美术或规则书全文；界面使用数字牌和自制布局。

## 牌桌动作的可见性

线上展示公开的拿牌来源、换牌牌位以及 PEEK/SPY/SWAP 的操作目标，模拟实体桌面上可见的手势；翻看的数值只传给获准查看的玩家。暗牌移动使用同一牌背，不增加可追踪的永久卡牌标识。动画按服务端已提交结果播放，不改变行动顺序、结算或牌的公开条件。


## 中途退出的线上约定

主动退出不作为 CABO 的计分动作，不额外罚分。座位由 AI 继续按相同规则完成本局；原玩家不能重返已接管座位。全员同意解散则中止整个房间，不进行本局胜负结算。投票暂停游戏行动和 AI，拒绝后继续。此功能属于房间生命周期，不是其他 CABO 版本或纸面家规。


## 可选的线上操作时限

操作时限是房间的线上约定，不是 2019 英文第二版新增的纸面规则。房主可在开局前设置不限时或 30/60/120/300 秒。初始看牌与盖牌共用一段时间；抽牌、换/弃牌及能力处理也共用整回合预算，中间点击不会重置。

超时采用保守的合法动作：未看起始牌时查看前两张并盖牌；未抽牌则从牌库抽一张并直接弃置，不发动能力；已从弃牌堆拿牌则换入自己第一个牌位；未使用的能力跳过，已翻看的牌自动确认。既不额外罚分也不自动呼叫 CABO，不永久接管玩家。回合结束仍按原版规则计分，本轮结算页由房主手动进入下一轮。投票暂停、刷新恢复与存档说明见 `docs/turn-limits.md`。

## 手卡版本提示（2026-10-24）

本次核对出版方 CABO 网页，页面同时给出全盖牌及四轮变体。本站当前专家开关只启用全盖牌，仍使用累计分终局；手卡明确提示这一范围，不把四轮制暗中混入现有存档或引擎。

## 起始看牌的并发提交

起始看牌阶段，各玩家的「查看」和「盖牌」是独立选择。其他玩家的起始操作不使自己的未提交选择失效。服务端在同一事务中核对对局、轮次、玩家与当前步骤；旧步骤不能重复提交，进入正式回合后仍按当前房间版本校验。
