# 自动玩家

房主在等待房间的空座位添加 AI，按游戏人数上限补足（CABO/魔毯商人 4 人，七大奇迹 7 人）。AI 自动准备，真人准备后即可开局；等待阶段可以移除。AI 不接管已有真人座位，开局后成员固定。房主转移只选择真人，最后一位真人离开等待/结束房间时连同 AI 一起清理。

## CABO 基础策略

- 起始查看并记住两张牌，自动确认。
- 根据记忆估计手牌，优先用较小牌替换较大牌，适时从弃牌堆拿牌。
- 使用 PEEK 了解自己的未知牌、SPY 查看对手暗牌，SWAP 尝试改善手牌。
- 手牌估值足够低时呼叫 CABO；每轮结束停下，由房主决定下一轮。

这是本地启发式策略，不使用大模型或网络服务，不保证最优，不主动尝试多张同值换牌。AI 只能读取自己的 `view`，记住合法看过的牌；其他玩家的交换目标不在公开视图中，因此遇到无法追踪的交换会保守地忘记旧信息。对手隐藏换牌也会使对应记忆失效。

## 平台边界

`packages/platform/bots.js` 每次房间状态提交后更新每位 AI 的记忆，默认间隔 800ms 执行一个行动。聊天通知不推迟 AI 行动。执行前重新检查 revision，并通过房间事务保存；通知仍按每位真人的投影推送。定时器在服务关闭时取消，启动后扫描现有对局恢复。策略失败会记录错误并停止本次调度，不无限重试；下一次房间变更可重新尝试。

只持久化房间名册的可选字段 `isBot: true`，缺省即真人；CABO 权威状态的结构和 `stateVersion` 没有改变。AI 无会话凭据。AI 记忆仅保存在进程内，服务器重启会遗忘过去看过的暗牌，仍可根据公开信息和后续查看继续行动。

验证涵盖人数与权限、旧 revision、移除与房主转移、信息隔离、普通/专家模式完整轮次、停止/恢复和真实 HTTP 单人开局。

## 七大奇迹

支持 3–7 人及全部日夜面，AI 默认选日面。仅根据自己的手牌和公开城市，评估资源、科技、军力、贸易费用及奇迹能力。确认后等待其他玩家，在陵墓回收与巴比伦额外行动时继续作出选择。无需网络或模型服务，主动离开的真人座位可由同一策略接管。详见 [第二版规则与实现边界](seven-wonders-rules.md)。
