# 卡坦岛玩家桌面

棋盘保持居中，其他玩家的资源总数、公开分数、道路长度和骑士数位于上方。玩家自己的资源在底部成组显示，资源名、数量与港口兑换率不依赖插画辨识。发展卡单独列出，购入当回合显示下回合可用。

右侧操作区先说明当前任务，再展示可执行按钮。选择建造类型后只显示合法落点，点击落点后还需确认，避免误建。七点弃牌自动展开个人弃牌面板，强盗和被抢夺玩家分两步选择。交易通过双向资源计数器报价，成交由服务器检查双方资源。

桌面采用深海色背景、暖纸色数字标记与六类原创地形插画。6/8 使用红色数字，概率以圆点表示。玩家颜色同时配合姓名和位置说明。棋盘以 SVG 坐标定位，交互使用原生 button，兼容项目禁止行内样式的 CSP。移动端改为上下布局、双列玩家信息与双列操作区。

## HUD 第二轮改版（玩家反馈）

参考 Colonist 的底部建造菜单、按需费用说明、玩家/银行独立交易模式，以及 CATAN Universe 官方媒体展示。采用交互模式与信息层级参考，没有复制其美术。

- [Colonist 官方交易设计复盘](https://blog.colonist.io/improving-the-colonist-trade-system/)
- [Colonist 官方界面说明与截图](https://blog.colonist.io/play-colonist-on-discord/)
- [CATAN Universe 官方媒体页](https://catanuniverse.com/en/media/)

移除大标题、副标题、桌面装饰文案、常驻教程、空发展卡说明和右侧说明栏。顶部保留紧凑玩家信息及当前玩家颜色标记；道路/骑士详情通过玩家提示查看。规则和日志通过 ? / ≡ 按需打开。

底部 HUD 集中自己的资源卡、建筑、交易、掷骰和结束回合。建筑和资源使用统一 SVG 图标，费用用小资源图标表达；缺少的资源变暗，不能执行的建筑按钮降亮度。开局免费放置不显示收费图标。

开局自动进入村庄/道路模式，合法位置以呼吸描边轮廓标记。选中后其他候选淡出，落点旁出现 ✓ / ×。顶部只保留一句与当前阶段相关的动作提示；其他人的回合不会要求自己操作。没有可建项目时直接提示交易或结束。支持减少动态效果偏好。

交易面板浮于棋盘边缘，区分玩家/银行，↑ 付出、↓ 获得。银行模式自动填入专用港口/通用港口比例，不让玩家手工凑数量。关闭帮助后若仍需弃牌，会回到弃牌面板。手机可放大棋盘并滚动查看，底部 HUD 保持独立。

验证：12 项卡坦岛测试通过；真实牌桌刷新、新交易页签、独立开局测试页面的村庄→原地确认→道路→键盘确认，以及 390px iframe 内的选点和棋盘缩放。截图 `work/catan/hud-v2-desktop.png`。本次只修改游戏 UI，未改规则或持久化状态。
