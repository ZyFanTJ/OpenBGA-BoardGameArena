# 潮汐守望 · 群岛防线

2026-10-28 更新。新对局使用规则版本 4、状态版本 4。1 至 4 人各守一岛，漏怪保留血量顺时针进入下一岛，全图怪物数量严格超过上限时全队失败，共 18 波。

## 品质与基座成长

卡池有 24 种基座，分潮汐、炉火、机巧、星灯四派系，每派六种。普通、精良、史诗、传奇仍各有固定概率和保底。卡片用整张品质底色，部署后用白、蓝、紫、金色底部光环区分，紫色与金色增加外环。派系使用固定主色和圆形图标，潮汐为青蓝水滴，炉火为橙色火焰，机巧为金色齿轮，星灯为紫色星光。主攻、辅助、控制、增幅使用独立的方形定位图标。卡片顶部放派系、品质与定位，名字单独占行；详情、进化配方和玩法手卡共用同一套图标。抽卡结果提示放进操作区的正常布局，不覆盖手牌。

每种基座有两个具名成长分支，共 48 条分支。选择分支后可以用金币从一级升到二级、三级，不能改选。二级费用为 30 加品质序号乘 15，三级为 55 加品质序号乘 20，品质序号从普通的 0 算起。成长会改变攻击节奏、范围、控制、连锁、燃烧、增伤、召唤或残血收割等效果。48 条分支由 12 类机制组合，具体数值见 `draft-catalog.js`。

同名两张一星仍可合成二星，公开配方仍可消耗建筑与核心进化成另一种基座。升星保留投入较高的成长线，两张已成长且分支不同的建筑不能升星。重复成长投入退回七成；进化为另一基座时退回原材料成长投入的七成，新基座从一级开始。抽卡、升星、成长和配方进化各有独立用途。

原抽卡、赠送与指挥规则见 [抽卡方案](tidewatch-draft-design.md)，额外出怪见 [悬赏召怪](tidewatch-bounties.md)。其中地块、成长和遗物获取节奏以本页版本 4 为准。

## 选路与土地

每岛扩大到 1200 × 900 的逻辑地图，共 32 个建造位。开局开放 24 个，其余八块需要 30 至 55 金币开垦。原来 16 个位置的编号与坐标保留，在路边和已有塔位之间补入 16 个位置，便于安排近距离辅助、分段控制和多路覆盖。整备期可花 10 金币把建筑迁移到空地，保留攻击等待时间。地图支持拖动、缩放和全图查看，所有视图保持自然比例。

| 路线 | 收益与用途 |
| --- | --- |
| 内湾长堤 | 无额外收入，路线较长，适合控制和持续伤害 |
| 近海商道 | 每波多 12 金币，路线更短，敌人更快漏出 |
| 环礁回廊 | 每波多 6 金币，绕过北侧高台，经过南部矿场 |

本波怪物全部出完、全图清空且没有悬赏等待入场时，立即进入下一波整备，不再要求战斗满 28 秒。点「下一波」可以提前开战，多人仍需要全员准备。未来普通出怪和等待中的悬赏不能被跳过，末波清场直接获胜。波次到时仍会自动推进，遗留怪继续存在。

有怪留在本岛时不能改线。跨岛怪按下一岛自己的路线继续前进，状态与剩余血量不重置。

| 地形 | 实际效果 |
| --- | --- |
| 高台 | 射程增加 20% |
| 风口 | 攻击间隔缩短 10% |
| 潮口 | 控制命中额外减速，浸潮多持续一秒 |
| 中继 | 辅助范围增加 35% |
| 矿场 | 辅助或增幅建筑每波额外提供 6 金币 |
| 平地 | 无额外加成 |

辅助和增幅建筑会支援同岛范围内的其他建筑，多个同类增伤取最高值。选中辅助塔可以看到作用范围和连接线。路线覆盖、主塔位置、辅助距离、矿场收益会争用资金与指挥额度。

## 遗物与 BD

遗物改为拥有后装备，四个位置为核心、供能、传导、终结。每件遗物有明确的适配位置，同件不能重复装备，整备期可以调整。总计 24 件，原有 16 件保留效果并分配位置，新增 8 件提供触发链、站位限制和收益取舍。同一件新增遗物装在不同适配位置时会产生不同效果。

正常遗物选择出现在第 4、7、10、13、16 波。首件派系遗物仍送紫卡，悬赏得到的额外遗物增加收藏或装入空位，不会扩展装备位置。

| 组合方向 | 关键选择与取舍 |
| --- | --- |
| 沸潮燃烧 | 沸潮心核把浸潮命中变成燃烧；放在传导位时，让同时浸潮和灼烧的目标更快积热，继续接炉火引爆 |
| 高频放电 | 快攻分支搭配蓄电飞轮，六次主攻击触发额外脉冲；供能与终结位分别围绕攻击次数和击杀蓄力 |
| 孤星主炮 | 孤星透镜要求 300 范围内没有另一座主攻塔，换取高伤害或射程；可用远处中继辅助连接主力 |
| 漏怪救援 | 渡海契约偏向击杀跨岛怪，鲜入场敌人的伤害有折扣，适合承担队伍后段防线 |
| 开垦运营 | 港税金印奖励付费土地或矿场支援，前期金币投入需要靠后续波次回收 |
| 越限速攻 | 越限机匣提高攻速但缩短射程，或提高收入但延长技能冷却，需要重新选位和安排救场 |

棱镜枢纽连接浸潮、星印与接力；余火灵匣传播灼烧或提前铺火。派生伤害不递归制造无限触发，区域与延迟效果有数量上限。部分遗物显示触发次数，具体效果以装备详情为准。

设计参考 [Slay the Spire](https://store.steampowered.com/app/646570/Slay_the_Spire/) 的组牌协同，以及 [暖雪](https://store.steampowered.com/app/1296830/Warm_Snow/) 的搭配方向。四个装备位、基座成长和具体效果为本项目设计，未使用这两款游戏的素材。

## 界面与存档

桌面默认显示地图和右侧操作区，手机使用上下布局。卡池、免费抽取、保底、技能保留在常用操作区，详细成长线和遗物效果按需打开。局内与局外手卡共用图文规则。右上角“统计”可查看所有玩家的累计击杀、累计金币与全队合计，面板随玩家投影实时更新，结束后仍可查看。金币使用已有累计收入，包含波次、路线、矿场、遗物经营和悬赏奖励，花费不扣减，不含开局资金、回收与其他返还。结算默认显示紧凑摘要与常用操作，个人表现折叠；桌面结算区限制在与游戏主体相同的宽度，手机保留地图，展开详情也不占满画面。现有原创图集继续随项目提供，运行时不依赖外部图片服务。

规则在 `packages/games/tidewatch`，界面在 `apps/web/games/tidewatch`。服务器权威计算，客户端只接收对应玩家的投影。规则转移保持无 I/O、不可变输入和可注入随机；修改房间状态时仍在持久化事务内核验版本。

当前状态版本为 4。版本 3 存档保留原建筑位置、已购土地、库存与私人进度，补入新增加的免费位置；新付费位置仍需开垦。版本 1 与 2 的存档迁移到版本 4 容器，分别保留经典与 V2 规则、界面到对局结束。V2 源码与说明保存在独立文件，详见 [V2 设计](tidewatch-v2-design.md) 与 [V3 记录](tidewatch-v3-design.md)。当前验证范围见 [验收记录](tidewatch-testing.md)。
