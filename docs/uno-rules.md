# UNO · 经典 108 张版

核实日期：2026-10-22。规则主源为 [Mattel W2085 英文说明书](https://service.mattel.com/instruction_sheets/W2085-Eng.pdf)，双人反转参照 [Mattel 42001 经典规则](https://service.mattel.com/instruction_sheets/42001pr.pdf)。使用 `classic-108-W2085-online-1`，首次存档版本为 1。

## 本作规则

牌组组成：红、黄、绿、蓝各 25 张。每色 0 一张，1–9 各两张，跳过、反转、+2 各两张；另有变色与 +4 各四张，共 108 张。每轮重新洗全副牌并逐张轮流发七张，余牌为抽牌堆，翻一张为弃牌堆顶。默认庄家左侧先行。相同功能符号允许跨颜色匹配，普通变色牌即使有可出的彩色牌也可出。

2–10 人，各发 7 张。顺序出一张同色、同数字或同符号牌，也可出万能牌并选色。可主动抽一张，只能打出刚抽到的牌，或保留。无可出新牌时自动轮转。跳过使下家停一回合；反转改变方向，两人时等于跳过。+2 抽两张并跳过，不能用 +2 抵消。+4 在没有当前颜色牌时才合法；允许冒险，受罚者可接受抽四并跳过，或质疑。成功时出牌者抽四，质疑者继续；失败时质疑者抽六并跳过。质疑证据仅质疑者可见。

剩一张须喊 UNO，漏喊被抓罚两张。末张 +2 / +4 先处理罚牌与质疑，再计分。数字按数值，普通功能牌 20，万能牌 50；本轮胜者得其他人剩余牌分，先到 500 分胜。牌库耗尽保留弃牌顶，洗回其余弃牌。

## 线上解释与明确选项

- 首轮由服务器等概率抽选庄家，取代实体逐人抽牌比大小；此后向左轮庄。实体规则的抽牌并列未定义，本作无需处理实体并列。
- 初始 +4 放回重洗直至翻出其他牌；变色由庄家左侧玩家选色；+2 / 跳过作用于该玩家，初始反转由庄家先行动并向右进行。双人初始反转沿用该初始规则，双人后续反转当跳过。
- 不混用 42001 旧版漏喊罚四张；采用 W2085 的两张罚牌。42001 只补充双人反转及开始行动的解释。
- 漏喊窗口到下一位出牌、抽牌或处理 +4 前关闭；服务器事务先收到的有效命令生效。支持随出牌同时喊 UNO，也能漏喊后补喊。没有人为倒计时窗口。自动 +2 的补罚不是玩家主动开始回合；窗口留给随后能行动的玩家。反转/跳过回到自己时，自己的下一次抽/出牌也关闭窗口。
- +4 连最后一张也保留接受/质疑步骤。质疑成功后 +4 留在弃牌堆，所选颜色继续有效，出牌者抽四而质疑者正常行动。证据使用打出 +4 当时的剩余手牌，避免之后补罚改变证据；仅当次质疑者可见，下一次正常抽/出牌清除服务端证据；客户端保留已收到的证据供阅读，直到关闭或下一轮。选择颜色与出万能牌在同一条命令内完成，避免中途空色。
- UI 默认勾选“剩一张时喊 UNO”，出牌前可取消。AI 总是宣告，轮到自己时会抓尚有效的漏喊，并只选择合法 +4；AI 与超时策略都只读取该玩家投影，保守接受罚四。
- 100 / 300 分为清楚标注的线上短局选项，500 为默认官方标准。仅实现经典个人累计得分赛，不含旧版伙伴赛、淘汰赛和另一种罚分计分。
- 不启用叠加、抢出、同值连出、7–0、换手牌、自定义万能牌、Flip、No Mercy 或手机游戏专属规则。[FFK04 官方介绍](https://service.mattel.com/us/productPopup.aspx?prodno=FFK04&siteid=27)的 112 张含换手及自定义牌，属于不同产品，不加入本牌组。
- 极端情况下没有可回收弃牌时，按实际可抽数量处理；主动抽不到牌则转交回合。不会凭空生成牌。
