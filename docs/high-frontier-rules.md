# 高边疆第四版：规则导读与在线房间开发索引

整理日期：2026-10-08。对象：High Frontier 4 All，以下简称 HF4。

本轮先完成规则资料搜集，并将已核对的核心机制用中文整理。**完整原文已保存于本地资料库；本文是开发导读，不是逐条完成验收的完整中文规则规格。** 所有规则号指向本轮保存的 PDF，资料入口、页数、版本差异见 [来源目录](high-frontier-sources.md)。本文的中文术语是工作译名。

## 1. 没玩过时，先认识这个游戏

玩家代表航天组织，取得技术专利、组装飞船、规划路线，在太阳系中勘探、建立工厂和殖民地。水既能作推进剂，也能在近地轨道充当货币。标准核心游戏按固定年数结束，以得分决定胜负。

一条典型发展路线是：取得发动机、采矿机器人及炼厂技术 → 发射到近地轨道 → 装配飞船并加注燃料 → 抵达目标地点 → 勘探取得采矿权 → 将设备转为工厂 → 生产更先进的设备或建立殖民地。途中可能需要补给、交易或更换飞船配置；这不是必须照做的固定任务链。

HF4 的主要难点有三个：设备需要完整的支援链才能工作；飞行受推力、燃料与地图路线共同约束；交易、政治和扩展会改变可用行动。因此在线版不能只实现“掷骰后移动若干格”。

建议研究顺序为开箱指南 → Space Diamonds / Starship Builder → Race for Glory → 完整核心 → 模组 0 → 模组 1、2 → 其余扩展。教学玩法省略或改写了一些核心机制，必须使用独立房间配置。Jump Start 提供预组装飞船，适合作为之后的入门房间候选。[核心 A1–A3；Tools 1 A–B]

## 2. 固定版本与规则优先级

核心 A2 规定：卡牌、剧本、教程或变体的明确特殊规则优先于一般规则；扩展规则覆盖核心；扩展之间冲突时以出版日期判断。仅启用某扩展时才使用相应扩展条文。

实际开发不能以模糊的“最新版”作版本号。每种房间配置应保存：

- 使用哪几册规则及其 SHA-256；是否采纳独立勘误。
- 地图、卡牌、玩家板及燃料轨的数据版本。
- 模组、变体、人数、年限、胜利条件。
- 规则实现版本及独立的存档状态版本。

本次官方索引日期、PDF 导出时间、书内更新日期并不总一致。模组 1、3 的官方离线 PDF 较旧；模组 2 书内写 1–5 人，而核心写 1–6 人。模组 3 封面泛写 1–6 人，但正文 3Ab 明确竞争玩法为 2–6 人且不支持单人。不要直接给所有配置统一开放 1–6 人。详见来源目录的版本问题表。

## 3. 状态对象和公共信息

| 对象 | 规则含义 | 开发时必须区分 |
| --- | --- | --- |
| Aqua | 位于 LEO 的水罐，可作为货币 | 远方地点的水不是可随处消费的钱 |
| 手牌 Hand | 持有的技术专利 | 尚未制造成地图中的实体设备 |
| 实体牌 Stack card | 已发射或外星生产的设备 | 所在牌堆、正反面、朝向、是否可运行 |
| Stack | 同处某地点的一组设备、人员及货物 | 核心有 LEO、Rocket、Outpost 1、Outpost 2 |
| FT 货物 | 作为货物存放的燃料罐 | 每罐计入干质量，不能直接按推进剂消耗 |
| 湿质量燃料 | 已加注进飞船的推进剂 | 按燃料轨消耗，与 FT 货物分开 |
| Claim / Factory / Colony | 采矿权、工厂、殖民地 | 分层叠放；不能合成一个“建筑等级”字段 |
| 地点 Site | 可着陆的天体地点 | 大小、含水量、光谱类型、特殊标记 |
| Glory / Heroism | 探索荣誉与英雄事迹标记 | 取得方式、携带人员、正反面与得分 |
| Sunspot Cycle | 年份及季节推进轨 | 每轮推进，可能触发事件或结束周期 |

核心六种专利牌为推进器、采矿机器人、炼厂、发电机、反应堆、散热器。白面是地球制造版本，黑面是太空制造版本；扩展还有紫面升级牌。[B2]

**手牌、FT 和牌堆公开可查看**，不应套用 CABO 的隐藏手牌。专利牌库顶牌正面公开，研究拍卖宣布后才能检查该拍卖牌背面，并会露出下一张牌正面。未公开的牌库顺序仍由服务器保管。[E1b；I2f]

每个地点最多一个采矿权、一个工厂、一个殖民地；同一空间可容纳多艘飞船。核心最多四种指定牌堆，不应任意生成无限前哨。具体超限处理要按 E3、E6 与交易规则执行。[E2–E6；H1a]

## 4. 核心开局和年度顺序

### 4.1 标准开局

按 C1–C8 完成阵营分配和人员面选择。将人员放在 LEO；准备每人对应颜色的棋子、质量标记、7 个小立方体、7 个圆顶、9 个采矿权圆片、两个前哨标记。立方体还可能被太阳周期和政治代表占用，不能假设始终可建 7 座工厂。

分别洗混六种专利牌库，白面朝上。初始 Aqua 数等于使用的专利牌库数量，核心为 6；队列和合同不计入牌库数量。快速开局另有规则，不能套用这里的数值。初始化六种光谱类型的开发轨，以及地图上的荣誉标记。单人及双人不放英雄事迹标记。人员卡政治影响力字母靠前者成为首位玩家并放置太阳周期方块。[C]

### 4.2 每一年

1. 从首位玩家开始，按座位顺序各进行一个回合。
2. 每位玩家可进行一次操作和一次火箭移动，可以只做其中之一、两者都不做，也可以自选两者顺序。
3. 自己回合可做多次自由行动，但一般不能插在一次移动或一次操作的中间。
4. 所有玩家完成后，推进太阳周期一格。跨过事件标线时掷事件骰并结算；跨过年资标线时移除一个周期标记。最后一个周期标记移除后结算终局。

启用扩展后可能有多艘飞船，每艘可移动一次；同一组件仍不能借由换船再次移动。[D；H1b]

核心标准为 4 个周期、48 年。核心正文列出模组 1 和／或 2 通常为 5 周期，Futures 为 7 周期；模组及变体还允许指定其他长度，因此最终年限应由选定配置明确给出。[A1；M1；1A2]

## 5. 核心九种操作

除特殊规则增加机会外，每回合只能选择一次操作。以下是机制索引；标记为故障触发的操作还须走故障处理流程。

| 操作 | 前提与主要效果 | 原文 |
| --- | --- | --- |
| 收入 | 从公共池获得 1 Aqua；模组 0 开启后被筹款操作替代 | I1、O2 |
| 研究拍卖 | 选择一种专利牌库顶牌进行拍卖；涉及所有符合条件的玩家 | I2 |
| 自由市场 | 卖出一张手牌，或卖出 LEO 中符合条件的黑面设备 | I3 |
| 发射 Boost | 支付总质量等额 Aqua，将一张或多张手牌以白面放入 LEO | I4 |
| 地点补给 | 原位取水、工厂补给或空气采集；分别检查设备、地点及产量 | I5 |
| 勘探 | 运行中的 ISRU 设备满足目标含水量条件后尝试获得采矿权 | I6 |
| 工业化 | 在己方未工业化采矿权处退役采矿机器人、炼厂及所需支援，建立工厂 | I7 |
| 外星生产 | 在光谱类型匹配的工厂，将一张手牌以黑面制造出来 | I8 |
| 交付 Delivery | 在工厂支付地点相关 FT，将一张设备送往 LEO/Bank；启用模组 1 后不可用 | I9 |

### 5.1 拍卖和市场

- 手牌已有 4 张或更多时，不能发起或参与研究拍卖。**这不是持有手牌的硬上限**；获胜时的附赠支援可以令手牌超过 4 张。
- 发起者必须首先出价，最低为 0 Aqua。其他合资格玩家可加价；原文不规定轮流出价。
- 发起者获胜时向公共池付款；别人获胜时向发起者付款。
- 平价涉及发起者则发起者优先；否则由发起者选择同价获胜者。
- 获胜者还取得拍卖牌直接需求的各类支援牌库顶牌。不会递归赠送这些支援本身所需的支援，也不保证附赠牌的子类型匹配。[I2]
- 自由市场卖手牌：牌回对应牌库底，获得 3 Aqua。卖 LEO 黑面实体：设备退役回手牌，收入由该光谱工厂股价确定，通常为 8、5、4；没有该光谱工厂时为 10。ANY 光谱黑面不能这样出售。[I3]

在线拍卖须明确“本次没有人再加价”的收口协议，但固定倒计时、自动放弃及断线处理属于产品选择，不是已经核实的桌游规则。

### 5.2 勘探、工厂和生产

普通勘探要求运行中的 ISRU 设备，且 ISRU 数值不大于目标含水量；数值越小，适用地点越广。掷六面骰不大于地点大小则成功，放置采矿权；失败放置 Busted 标记，以后不能再次勘探，但仍可以着陆及原位取水。月球的普通勘探另需首位玩家许可。[I6]

光束型可对规则定义的邻接地点进行多目标勘探，先选完目标再掷骰；大气会限制远程勘探。车式设备有一次失败重掷机会，黄色道路连接地点另有多地点规则。导弹型没有此类特殊加成。邻接判定会忽略特定危险格和着陆格，不能直接复用地图“一条边”的定义。[I6a–c；Glossary: Adjacent]

工业化必须使用采矿机器人和炼厂，人员不能替代机器人。两者可共用支援；工业化对散热有特例，不要求提供或退役散热器。工厂的光谱由地点决定，与被消耗设备的光谱无关。工厂建立或撤除后应更新全局开发轨：某光谱的工厂越多，对应股价越低。[I7]

外星生产将一张手牌变成当地黑面实体，不等于复制一张额外专利。设备要真正执行动作，还须满足相应支援与运行条件。[I8；J]

本次核心 I9 已明确允许交付白面或黑面牌；费用为与 LEO/Bank 相隔日心区数量的两倍 FT，地点大小至少 7 再加 1 FT。同周期彗星在所有季节都可使用交付。不要用旧版“仅黑面交付”的摘要实现。[I9]

## 6. 自由行动、飞行与设备运转

### 6.1 自由行动清单

G1 同地点货物转移及相关加注／卸载；G2 内部燃料罐形式转换；G3 建立殖民地；G4 夺取采矿权；G5 装载荣誉；G6 自愿弃置／退役；G7 故障维修。政治模组还增加游说，某些卡牌能力也有自己的次数和时机限制。

建立殖民地需要在己方无殖民地的工厂处退役一张人员牌，再放圆顶；人员由此成为定居者。采矿权夺取需要满足 Felony 规则，不能夺取有工厂或反对方人员守护的采矿权。[G3–G4]

故障牌堆与任何人员同地时可移除故障，也包括其他玩家的人员。不能把维修写成“必须拥有自己的船员”。[G7；N8]

自愿弃置和退役是不同动作；人员、采矿权、殖民地、已殖民工厂及代表等存在限制，不能提供一个可删除任何对象的按钮。资源数量不足时的回收也是具体规则，不是无限供应。[E7；G6；I7f]

### 6.2 质量与燃料

干质量由设备牌与 FT 货物组成；湿质量再包含已加注推进剂。每个 FT 货物质量为 1。移动需要干质量不超过 23、湿质量不超过 32；零干质量按 1 处理。[E2a；F]

**燃料罐数量、湿质量数值、燃料轨上的消耗步数不是同一量。** 添加燃料与消耗燃料沿玩家板的不同轨线移动；改变载荷还会同时调整干湿质量。开发应把玩家板燃料轨录成可校验的数据和转移函数，不应简单实现为每次燃烧减一罐水。原件第 15–17 页和玩家辅助表保留了示意图。

燃料有灰色尘土、蓝色水、金色同位素三个等级。发动机不能用低于自身要求等级的燃料燃烧；不同等级推进剂混装后全部降为较低等级。货物可分别携带蓝、金 FT。同位素发动机激活还有最低燃料要求；零耗油太阳帆另有特殊处理。[F4；H2]

### 6.3 一次飞行的检查次序

1. 调整质量标记，检查飞船是否满足移动限制。
2. 选择本次激活的推进三角及完整支援链；飞行中不能换发动机或支援链。
3. 按 H3 顺序应用后燃、质量级别、太阳区、光束供能和支援修正，确定净推力。
4. 沿地图逐段移动；进入燃烧格与执行转向燃烧时结算燃料和燃烧额度。
5. 处理沿途危险、飞掠、辐射、着陆及强制停止条件；结束移动后才恢复普通自由行动／操作窗口。

净推力约束的是本次可进行的燃烧次数，**不是可经过的地图格数**。每次普通燃烧消耗步数取决于发动机燃耗。无图标的 Hohmann 交汇处在同一次飞行中转弯需两次燃烧；在此停留到下一回合再转向则不用支付该转向代价。带图标的交汇点可按规则免费转向。进入某格后不能立即沿来路折返。[H2–H5]

动力着陆／起飞要求净推力严格大于地点大小；大气制动、工厂辅助、半着陆燃烧、太阳帆及特殊设备有各自分支。着陆通常结束移动，着陆燃烧格不能随意停车。燃料不足或失去发动机后，有时仍能按滑行规则前进。[H4–H8]

每个组件本回合移动一次的限制要跟随设备和燃料，即使转移到另一艘船、燃料转换为 FT 再转换回来，也不能重置。[H1b]

### 6.4 支援链

需要的发电机、反应堆、散热器必须具备正确类型／子类型，并处于可运行状态。支援可以有自己的支援需求；同一支援可以服务多个设备。散热额度需单独分配，不能无条件重复计算。[J1–J5]

特别需要注意 J1e：部分脉冲发电机和反应堆允许互相支援。通用图算法若把所有环都判成非法，会错误拒绝合法组合。引擎应区分明确允许的循环与无法成立的设备组合。

## 7. 事件、交易和终局

### 7.1 周期事件

跨过事件标线掷 1d6：1–2 为灵感，3 为故障，4 为发射台爆炸／太空碎片，5–6 由当前季节决定。[K2]

| 事件 | 主要结算 |
| --- | --- |
| 灵感 | 各专利牌库及适用的殖民者队列顶牌移到底部 |
| 故障 | 各玩家在符合条件且牌最多的牌堆放故障；有故障或同地有人类的堆不符合条件 |
| 发射台爆炸／碎片 | 各玩家 LEO 中非豁免牌的最高质量牌退役；并列由该玩家选 |
| 红季太阳耀斑 | 另掷严重度，按日心区修正，与每张牌耐辐射值比较；地点、LEO 等有屏蔽 |
| 蓝季无政府状态 | 指定阵营特权临时被 Felonious 替代；政治模组另有法律失效和清洗 |
| 黄季预算削减 | 各玩家选择一张手牌放回对应牌库底；无手牌者不弃牌 |

多人选择按首位玩家起顺序结算。不能把所有受影响对象立即随机删除。故障标记本身不立即炸毁设备；后来进行故障触发动作时才按相应故障骰处理。事件骰、故障骰、危险骰、辐射骰是不同机制。[K2；Glossary: Glitch Trigger]

### 7.2 交易与协商

玩家可在其他玩家回合中协商。当前回合无法履行的未来承诺不具强制约束力。Aqua、手牌、牌堆／产权及特定服务的交易各有规则和时机；实体物品转移不能插入移动、操作或自由行动中间。[N]

手牌收到后存在防止立即转卖的时机限制；人员乘坐别人飞船也不代表所有权转移。荣耀、Futures、已锚定 Bernal 和升级牌等通常不能自由转让，需按原文例外处理。聊天中的一句承诺不能自动触发资产转移。[N1–N8]

### 7.3 荣誉、英雄事迹及胜负

人员抵达相应日心区地点可取得未被拿走的荣誉，先以低分面携带；带回 LEO/Bank 后翻为高分面。每名人员只能携带一个。人员退役时，荣誉以低分面进入玩家荣誉区。[G5；L]

英雄事迹只用于至少三人的游戏，可由玩家提名和投票授予，在最后一年之前办理，首位玩家处理平票。在线版应保留这一投票步骤，不能全部改成自动成就。[Lc]

核心终局以总 VP 排序；同分比较 Aqua，再同分共享名次。地图上的玩家色木／塑料标记各有基础分，工厂另加开发轨股价，殖民地按地点特征有加分，荣誉按朝上面计分。纸质前哨标记不因此得到棋子分。模组 0 代表和终局法律、后续扩展的殖民地、Futures、合同等会增加或改写项目。[M2]

## 8. 模组 0：政治

核心书第 41–43 页收录政治，但是否启用仍是配置选项。开启后，以筹款操作替代收入操作：取得基础 1 Aqua，可在符合条件的意识形态中新增一名代表，再可将自己一名代表移到相邻意识形态；戒严及特定法律会修改步骤。[O2]

影响代表的操作／自由行动／能力／清洗完成后点票，最多代表的意识形态决定有效法律；平票存在当前行动玩家选择，无代表时转中间派。普通代表与每个周期加入的历史票不同，历史票只在终局参与点票。[O3；O6]

| 意识形态 | 法律效果的核心内容 |
| --- | --- |
| Freedom | 自由市场可将两张手牌合卖 5 Aqua |
| Honor | 筹款收入按持有的荣誉数量计算，可能为零 |
| Unity | 其他拥有至少两名代表的意识形态法律也启用，禁止游说 |
| Authority | 筹款可弃掉一名对方代表；影响周期末首位玩家交接 |
| Equality | 发起研究时不拍卖，付 1 Aqua 取顶牌；无附赠支援且不受学术手牌限制 |
| Individuality | 指定用途可使用对手工厂／Bernal，但不通用于升级或 Futures 条件 |
| Centrist | 发射台事故保险，赔偿和游说有专门时机 |

通常游说是每回合一次的自由行动，支付 Aqua 并消耗非有效意识形态中的己方代表以临时使用该法律。中间派保险是跨回合的特殊窗口；无政府、战争和模组 3 会改变规则。[O4–O5]

终局最后一次点票影响奖励：Freedom 奖工厂，Honor 奖荣誉，Unity 奖有代表的意识形态种类，Authority 奖采矿权，Equality 奖殖民地，Individuality 奖危险着陆地点上的适用棋子；中间派无额外政治分。[O6–O7]

## 10. 接入本仓库时的开发边界

以下是工程建议，**不是官方桌游规则**。已对照仓库 `docs/adding-a-game.md` 和 `packages/platform/game-contract.d.ts`。

1. 使用 `packages/games/high-frontier/` 放规则与数据，`apps/web/games/high-frontier/` 放界面。平台继续只处理房间、会话、聊天、传输和持久化。
2. 游戏模块实现 `create/apply/view/isFinished`。所有转换保持纯函数，注入随机源；不在规则内下载资料、读取时钟或写文件。
3. 使用显式阶段表示年度回合、拍卖、飞行、事件选择、协商确认、投票及终局。获准提交命令的人由当前等待事项决定，不能一律限定为回合玩家。
4. 操作需要其他玩家选择时，保存可恢复的待决上下文，不依赖前端临时弹窗。断线重连后应恢复同一个决策。
5. 公开手牌也仍走玩家专属 `view`；不能将完整权威状态直接推送客户端。未揭示牌库顺序和随机内部信息必须排除。
6. 平台继续在与持久化相同的事务中校验 revision。多人拍卖、交易与事件响应同样不能绕过。
7. 地图要录为带路线属性的图，保存方向和转向关系；地点清单不足以替代完整地图。燃料轨也须单独数据化和校验。
8. 卡牌数据要逐面、逐朝向记录质量、耐辐射、推力、燃耗、支援、ISRU、能力、升级与对应规则号。公开参考表是录入材料，不是已校验数据库。
9. 存档须固定规则快照；状态结构改变时增加 stateVersion 并提供迁移。

### 10.1 后续实现验收用例

| 用例 | 必须验证的结果 |
| --- | --- |
| 3 张手牌研究并获附赠支援 | 可以超过 4 张；下一次不能参与普通拍卖 |
| 发起拍卖却被别人拍得 | 钱给发起者，不进公共池 |
| 发起者平价／两名其他玩家平价 | 分别走优先权／选择获胜者 |
| 火星储水与 LEO 钱包 | 火星 FT 不可支付普通 Aqua 拍卖 |
| 加注、卸载、内部 FT 转换 | 分别使用正确的干湿质量轨转移 |
| 同一 Hohmann 当回合转弯／隔回合转弯 | 前者支付转向燃烧，后者无需 |
| 设备转移到另一飞船 | 已移动组件不能再移动 |
| 共享支援、脉冲发电机与反应堆互相支援 | 合法组合不能误判，散热不能重复占用 |
| 工业化时缺散热器 | 应用 I7g 的特例，不能沿用普通运行判定直接拒绝 |
| 失败勘探的地点 | 不能重勘，但可按条件补给 |
| 白面设备交付 | 本次核心快照允许；启用模组 1 则无交付操作 |
| 人类同地修复对手故障 | 正确开放维修，且按 N8 处理 |
| 预算削减多人选择中断线 | 继续同一个顺序与待决事项 |
| 最后一个周期与政治历史票 | 先完成适用终局点票，再套用政治评分 |
| 开启模组 6 | 用对应 DP 规则判胜，不沿用核心 VP |
