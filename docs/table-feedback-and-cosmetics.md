# 牌桌反馈、断线恢复与外观

## 行动与结算

行动提示以服务端 `turn.playerIds` 为准，同时行动的游戏可以有多位玩家亮起。真人、AI 和自己使用同一套 2.4 秒呼吸光；发光不改变 HUD 的尺寸。系统开启“减少动态效果”时改为静态描边。

CABO、UNO 和忍者之夜的非房主轮末结算提供可展开的等待说明，说明下一轮由谁开启、会自动进入。UNO 可通过关闭按钮或 Escape 收起本轮结算，也可以再次打开；新一轮到达后自动恢复游戏操作。整场比赛结束仍使用最终战绩操作。

## 连接与操作

协议 2 的 SSE 每 20 秒发送命名 `heartbeat` 事件，事件仅含时间，不含游戏状态。协议 1 保留注释心跳。前端每 5 秒检查一次，超过 45 秒没有收到心跳或牌局事件会关闭旧连接并恢复；浏览器离线事件立即显示断线提示。

连接恢复采用 1.5 秒起步、最多 15 秒的退避，先读取玩家自己的最新快照，再重新订阅。恢复网络或回到长时间休眠的页面也会重新同步。离开房间会清理连接、定时器和事件监听。登录失效时停止重试；无权访问或房间已关闭时退出旧牌桌。

版本冲突使用明确的 `ROOM_REVISION_CONFLICT` 错误码。只有服务端明确拒绝、比赛与操作窗口相同、完整玩家决策视图未变化的游戏操作才重试一次。局面已变化时同步并提示重新选择；结果未确认的网络写入永不重放。设置等操作遇到冲突保持失败，避免显示虚假的保存成功。

卡背为原创 SVG，仅装饰该玩家的暗牌，以及当前查看者的抽牌堆；不改变正面、数值、规则或任何私有投影。未知或跨游戏的外观 ID 回落到默认卡背。装备后向同桌广播各自的公开外观投影，不推进游戏版本。个人资料编辑保留独立外观槽。

外观槽是现有个人资料 `equipped` 字典的可选项，旧资料缺省显示默认外观；不修改游戏存档结构或规则版本。

## 验证

自动化覆盖心跳超时、离线恢复、过期登录、旧请求隔离、有限冲突恢复、未确认写入不重放、购买与独立装备、资料保存、实时外观广播及私有状态隔离。

浏览器使用内存测试资料验证 PC 与移动端的行动提示、断线自动恢复、房主开启下一轮后同桌自动进入、结算收起与展开、商城购买装备卸下、按游戏筛选和真实牌桌卡背。不使用开发或生产存档创建测试数据。
