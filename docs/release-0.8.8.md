# 0.8.8 更新内容

2026-10-24。相对云端 0.8.7 整理。

- **新版大厅**：使用 React 呈现游戏目录、分类筛选、搜索和分页；移动端首页每页显示六款游戏，优化推荐区、快捷开桌和游戏封面。保留“我要独自与AI练习，然后惊艳所有人”文案。
- **推荐与管理**：管理员可配置热门游戏，目录按热度展示；增加对应管理设置和校验。
- **CABO 操作反馈**：自己的行动倒计时放在操作提示附近，改进发牌动画、初始看牌和刷新恢复；准备阶段与重连后的动画提交独立处理。
- **行动提醒**：当前行动者和自己的回合使用更明显的金色呼吸光，保留减少动态效果偏好的兼容。
- **玩家身份**：好友显示在线状态和距上次在线的时间；论坛主题与回复展示作者当前头像、头像框和装备称号。
- **构建与资源**：增加大厅前端打包与开发监听，支持 JPEG 静态资源及新增封面素材；运行镜像携带已打包的前端资源。

平台逻辑数据仍为 v9，既有游戏状态结构及版本不变。线上账号、会话、资产、战绩、好友、论坛和 AI 配置保留，不复制本地玩家数据到云端。

已发布到云端。本地固定快照及云端构建均通过 **442/442** 项测试；发布前核验 **359** 个公开资源和 **438** 个运行文件。隔离浏览器验证新版大厅筛选、CABO 建房与 AI 开局、初始看牌、刷新恢复、返回大厅、论坛身份显示及 390px 手机大厅。

发布前完成真实数据只读兼容性检查和 SQLite 备份恢复演练；切换后逐项核验原有数据，先前定向复制的 7 场战绩及其隔离标记保留。部署细节与回退信息见 [remote-deployment.md](remote-deployment.md)。
