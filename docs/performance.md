# 静态资源与首页性能

保留原素材、分辨率、版式和游戏动画。WebP 使用无损编码，独立封面和展示牌仅裁切原图，不重新采样；生成脚本逐像素验证输出。

## 首页

- 游戏渲染器通过 `games/lazy.js` 在真正展示牌桌时加载。大厅只读取游戏元数据和轻量封面，等待房间也不会加载三个游戏的交互模块。离开页面后，未完成的加载不能重新覆盖当前页面。
- 游戏卡片初始隐藏，目录测量列宽后只显示当前页，避免首次布局就下载所有隐藏封面。翻页、搜索和分类会加载对应原图裁片。
- 主横幅在进入大厅时标记高优先级预加载；其他子页面不会额外下载横幅。七大奇迹封面使用原生图片懒加载。

## HTTP

`apps/server/static.js` 负责公共文件的静态响应。HTML、JavaScript、CSS、SVG 使用 Brotli 或 gzip，编码结果按文件的修改信息缓存在进程内；更新文件会重新计算内容和 ETag。

带 `-v数字` 的图片使用一年 immutable 缓存。代码、样式和 HTML 使用 `max-age=0, must-revalidate`，通过内容 ETag 返回 304，更新后仍及时获取新版本。压缩响应包含 `Vary: Accept-Encoding`。HEAD、文件不存在和原始 PNG 兼容路由保留。

API、会话、玩家资料、房间快照与 SSE 保持 `no-store`，不进入静态文件缓存。
